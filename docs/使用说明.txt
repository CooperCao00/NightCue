NightCue 1.3.1 · 夜色提醒

默认每天 23:00 开始夜间提醒，次日 07:00 结束，按 Windows 本地时间判断。
运行 NightCue.exe 即可，无需管理员权限。再次运行会显示已有实例的设置，不会重复启动。
需要 .NET Framework 4.8 或更高版本。当前本地验证环境为 Windows 11；Windows 10 是兼容目标，尚未经过 Windows 10 真机验证。

提醒方式
工具只安静地改变托盘图标，不发声、不弹通知、不闪烁、不抢输入焦点。
只有主动点击主题命令或按快捷键才会更改主题，结束时间后也不会自动切回浅色。
首次使用请将 NightCue 从时钟旁的隐藏图标区拖到任务栏，或在 Windows 任务栏设置中启用显示。托盘菜单也提供引导。图标显示由 Windows 管理，软件不能自行强制固定。

图标含义
琥珀色月亮：已到夜间提醒时间，等你方便时选择。
金色太阳：结束时间后，等待你选择是否切回浅色。
灰色圆环：等待、正在延后，或本时段已处理。
蓝色月亮：已是深色，当前没有待处理提醒。

托盘操作
左键：直接打开或激活设置；关闭后重新创建，最小化后恢复。1.3.1 修复了关闭设置后无法重新打开的问题。
右键：打开以下快捷菜单。
切换深色 / 浅色：切换 Windows 系统与支持跟随系统的应用主题。
稍后提醒：默认延后 15 分钟，可设为 1–120 分钟；到时安静地恢复对应提醒图标。
今晚保持浅色：切为浅色并停止当晚提醒。
本时段保持深色：切为深色并停止本次白天提醒，直到下一次开始时间。
恢复提醒：取消本时段的延后或忽略，重新显示需要处理的提醒。
设置：修改时段、延后时间、登录启动、快捷键、语言及结束时间后的浅色提醒。
退出：停止本次运行；如需永久停止登录启动，先在设置中关闭并确认成功。

早晨浅色提醒
默认开启“结束时间后提醒切换浅色”。默认时段下，07:00 至下一次 23:00 之间仍是深色时，显示金色太阳。
你可以切换浅色、延后或选择本时段保持深色，也可在设置中关闭这项提醒。
白天和夜间的选择、延后时间分别保存，退出重开后仍保留。每个新时段只重置自己的选择，跨午夜不会随意清空。
已经观察到目标主题后，视为本时段已处理；随后在其他地方切回另一主题，不会再次催促。需要时可主动恢复提醒。

语言
同一个 EXE 内置英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语、俄语。
默认跟随 Windows 显示语言，不支持的语言回退到英语。选择其他语言会立即应用并自动保存；关闭设置不会撤销已保存的更改。
字体随界面语言选择，并使用 Windows 的字体回退。系统原生对话框按钮可能仍按 Windows 自身语言显示。
更改 Windows 显示语言后，选择“跟随 Windows”的 NightCue 会在下次启动时读取新语言。

快捷键与专注
Ctrl + Alt + Shift + D：切换浅色 / 深色。
快捷键被其他软件占用时，设置窗口会提示，托盘菜单仍然可用。
程序不会检测房间开关灯，也不读取当前应用、会议或键盘输入来判断专注状态。
“15 分钟”表示主动选择延后后的等待时间，不是每隔 15 分钟弹窗。
休眠时不唤醒电脑，恢复运行后按当前时间判断；运行时提醒约 10 秒内刷新。

自动保存
开关和语言立即保存。两个时间在按 Enter 或离开整个时间区域时一起校验应用；分钟输入在按 Enter 或离开输入框时应用，加减按钮立即应用。
关闭设置或点击“收起到托盘”也会尝试提交有效草稿。未填完整或无效的草稿允许关闭并沿用原有效配置，已经生效的设置不会撤销。有效的时间或分钟草稿若写盘失败，窗口保留并显示行内提示以便重试，不弹对话框。
设置文件写入失败时在对应控件旁提示：提醒/快捷键开关和语言恢复原值，数字保留草稿以便修正，原有效值继续运行。
主题按钮仍在主动点击时切换，自动保存设置不等于按时间自动切换主题。

数据、迁移与卸载
settings.xml 保存设置、state.xml 保存白天与夜间状态，仍在程序旁边。日志与恢复文件在 %LOCALAPPDATA%\NightCue\Diagnostics，可从设置中点击“打开诊断”访问。
全部本地运行，无网络请求、统计上报或自动更新。请使用有写入权限的目录。
移动文件夹后，先退出旧实例，再从新位置运行，若注册项指向旧位置，点击“修复启动路径”；成功后该按钮恢复为“Windows 启动设置”。
设置状态区分未注册、已注册当前程序、已注册其他位置、无法读取注册信息。自启动开关立即应用；失败会显示提示并重新读取实际注册状态，若仍无法读取则禁用启动控件并显示未知状态；读取失败只阻止自启动更改，其他设置独立保存且不改启动项。
“Windows 启动设置”打开系统启动应用页面。Windows 可能另行禁用已注册的应用，NightCue 不会自动覆盖此决定；需要时由你在系统设置或任务管理器中重新启用。注册路径正确不等于已经验证重启登录成功。
升级：退出旧版，替换程序文件，保留 XML。旧设置默认跟随系统语言并开启早晨提醒，原夜间选择保留。
设置或提醒状态无法加载时，受影响文件使用默认值，左栏会持续显示恢复提示。损坏或无效文件先备份原件，成功后才尝试保存默认值。
读取或备份失败时，仅使用内存默认值，本进程禁止写入对应原件；修复权限后重启重试。
“关闭恢复提示”只关闭提示，不删除备份，也不解决原有问题。请打开诊断查看详情。
error.log 与 diagnostics.log 各限制为 128 KiB，并各保留一个 .1 副本；recovery.pending 保存未确认提示，带 .corrupt-时间-唯一标识.bak 后缀的文件是原件备份。关闭提示不会自动删除备份。
卸载：关闭登录启动并确认成功，从托盘退出，再删除程序文件夹。当前主题保持你选择的状态。诊断文件仍留在本地应用数据目录，不再需要时可另行删除。
日志和备份可能含本机路径或配置内容，公开分享前请检查。

应用或网站需支持跟随系统主题。自行固定主题的应用不受影响；请避免其他工具同时定时切换主题。
