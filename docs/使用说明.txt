夜色提醒

默认每天 23:00 开始，次日 07:00 结束。
运行 NightCue.exe 即可。再次打开同一个文件会显示设置，不会重复启动。

它只改变托盘图标，不发声、不弹通知、不抢走输入焦点。
没有点击切换或按快捷键时，它不会改变 Windows 主题。
提醒时段结束也不会自动切回浅色。

第一次使用
如果月亮图标藏在任务栏右侧的 ^ 菜单中，请将它拖到时钟旁。
持续可见的图标才能起到轻提醒作用。

图标
琥珀色月亮：已到提醒时间，等你方便时选择。
灰色圆环：未到时间、正在延后，或者今晚已处理。
蓝色月亮：当前已经是深色模式。

点击或右击托盘图标
进入深色模式：切换 Windows 系统和支持的应用，并停止当晚提醒。
切换到浅色模式：切回浅色；在夜间操作时停止当晚提醒。
15 分钟后提醒：暂时变为灰色圆环，到时恢复琥珀色月亮。
今晚保持浅色：切为浅色并停止当晚提醒。
恢复今晚提醒：取消延后或当晚忽略，恢复提醒；深色状态下无需提醒。
设置：修改开始、结束时间、延后分钟数、登录启动和快捷键。
退出：停止本次运行；如需永久停止，请先在设置中关闭登录启动。

快捷键
Ctrl + Alt + Shift + D：切换浅色 / 深色。
如果快捷键被其他软件占用，设置窗口会提示；托盘菜单仍然可用。

专注时的行为
工具始终没有声音、横幅、闪烁和自动弹出的窗口。
不会因为没操作鼠标键盘就判断你“不专注”，也不读取当前应用、会议或键盘输入。
“15 分钟”仅表示你主动选择延后后，标记恢复的时间，不是周期性弹窗。

其他说明
选择和延后时间保存在同一文件夹中，跨午夜、退出重开后仍然保留。
下一晚自动恢复提醒；休眠期间不唤醒电脑，恢复运行后检查当前时间。
系统当前已经是深色时，停止该晚提醒。
切换使用 Windows 的系统/应用主题设置；支持跟随系统主题的应用会响应。
自己固定为某个主题的应用或网站可能需要另行选择“跟随系统”。
请避免同时让 PowerToys Light Switch 或 Auto Dark Mode 定时改主题。

文件和卸载
settings.xml：设置；state.xml：当晚选择；error.log：出现错误时才生成。
全部本地运行，无网络请求；需要 .NET Framework 4.8 或更高版本。
MIT 许可证，署名 NightCue contributors；许可全文见随包 LICENSE。
卸载：设置中取消“登录后自动运行”并保存，托盘菜单选择退出，再删除此文件夹。
请不要在启用登录启动后移动文件夹；如需移动，请先关闭登录启动，移动后再重新开启。

升级：先从托盘退出旧程序，再将新包解压到原位置，保留 settings.xml 和 state.xml。
若因配置损坏无法启动，请先退出，备份并重命名 XML 文件，再重启程序。
error.log 可能包含本机路径，公开分享前请检查。
